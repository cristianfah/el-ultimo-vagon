# Personajes

Biblia v2 (18-oct-2026). Se mantiene el elenco y el casting visual aprobados el 2026-10-01; cambia lo que cada uno esconde. Ahora todos los secretos tocan la trama grande, no solo el triángulo.

Cada personaje tiene una **postura** en el debate. El público debe poder decir «yo soy como ella» o «ese tiene razón».
