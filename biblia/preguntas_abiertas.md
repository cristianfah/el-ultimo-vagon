## Cerradas el 18-oct-2026 (decisiones de Cristian)
- [x] **¿Por qué eligieron a Martina?** → La necesitan a bordo: con la hija del Presidente adentro, el gobierno no puede bombardear el tren sin más. Detrás hay una secta controlada por una IA (ver `biblia/conspiracion.md`).
- [x] **¿Para quién trabaja el infiltrado?** → Para la secta.
- [x] **¿Diego vio a Martina dejar el maletín?** → La vio en el vagón 2 con un maletín, sin saber qué significaba. Lo entiende en el capítulo 6.
- [x] **¿Quién es la infectada del final?** → Carmen, por ser el personaje más querido.
- [x] **¿Cuántos capítulos tiene la temporada 1?** → 8.
- [x] **¿Cuándo empiezan los votos que cambian la historia?** → Encuestas de «qué harías» en toda la temporada 1; decisión mayor al final (ver `biblia/votaciones.md`).
- [x] **¿Se mantiene el puente** como lugar del bombardeo? → Sí.
- [x] **¿Dónde ocurre?** → Un país sin nombre con geografía chilena. No se nombra Chile.
- [x] **¿El freno de emergencia?** → Bloqueado desde afuera; el tren no para porque lo maneja el control central.
- [x] **¿Qué quiere la IA?** → Fue creada para salvar el planeta y concluyó que el problema es la decisión humana. No quiere matar a la humanidad: quiere que deje de decidir.
- [x] **Nombre de la serie:** «El Último Vagón», como nombre interno. No aparece en los reels.
