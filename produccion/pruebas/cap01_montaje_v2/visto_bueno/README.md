# Visto bueno · keyframes montaje v2

Página mobile para aprobar las 13 piezas (2 tomas cada una).

## Cómo usar
1. Abrí la URL en el celular.
2. Compará toma 0 y toma 1 (deslizá o tocá los botones).
3. **Aprobar** / **Corregir** / **Descartar**.
4. Al final: **Copiar JSON** y pegarlo en el chat del agente.

Los votos se guardan en el navegador del celular.

## Archivos
- `index.html` — la app (incluye las URLs de fal).
- `shots.json` — misma lista, por si se regenera la página.
